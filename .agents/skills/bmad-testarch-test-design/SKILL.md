# TestArch Test Design

## Purpose
Applies formal software testing techniques to design comprehensive test suites with minimal redundancy.

## Techniques Applied
1. **Equivalence Partitioning (ECP)**: Partition input domain into valid and invalid equivalence classes.
2. **Boundary Value Analysis (BVA)**: Test minimum, nominal, maximum, and out-of-bound edge values.
3. **Decision Tables**: Map combinatorial input states to expected system outputs.
4. **State Transition Testing**: Verify all valid and invalid state changes in finite state machines.
