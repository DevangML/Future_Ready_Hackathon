# BMad Teach Me Testing

## Purpose
Interactive testing coach that guides developers through testing principles, patterns, and anti-patterns.

## Topics Covered
1. **Testing Heuristics**: Boundary conditions, zero/one/many, null/empty/overflow, timing/concurrency.
2. **Test Smells**: Assert Roulette, Mystery Guest, Fragile Tests, Over-Mocking, Tautological Tests.
3. **Test Doubles**: Differentiating Dummies, Stubs, Mocks, Spies, and Fakes.
4. **Advanced Paradigms**:
   - Property-based testing (generative fuzzing)
   - Mutation testing (testing the test suite)
   - Contract testing (Pact / OpenAPI)
